# vectifi.github.io

Company landing page. React 18 + TypeScript + Vite 6, Tailwind v4, Radix UI; Supabase for backend calls. Originally exported from Figma. Deploys via GitHub Pages; `/app` redirects to `my.vectifi.com`.

## Run

```bash
npm i          # install
npm run dev    # vite dev server
npm run build  # vite build (production bundle)
```

No test script — this is a static marketing site. Keep it lightweight; see `README.md`.
